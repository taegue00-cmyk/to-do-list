# 나의 할 일 목록 (To Do List)

간단한 HTML/CSS/JavaScript 기반의 할 일 관리 웹 앱입니다.

## 기능

- 할 일 추가
- 전체 / 진행중 / 완료 필터링
- 완료된 항목 삭제
- 전체 개수 및 완료 개수 통계 표시

## 사용 기술

- HTML5
- CSS3
- JavaScript (Vanilla)

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 사용할 수 있습니다.

## 파일 구성

- `index.html` – 앱 마크업 구조
- `style.css` – 스타일
- `main.js` – 할 일 추가/필터링/삭제 로직
